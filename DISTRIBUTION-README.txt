PANDORA CONNECTION SETUP (REQUIRED)
Public builds do not contain Pandora partner connection settings. Obtain one
separately from your integration provider or administrator. It is not your
personal Pandora password. After installation, open Pandora connection setup
on the sign-in page, enter all three supplied values and save them. Windows encrypts it
for your current Windows account on this computer. Then sign in normally with
your personal Pandora email and password. Without a partner connection value,
the installed application cannot sign in or play music.

HOURNERD MUSIC PLAYER 1.1.3

GET STARTED
1. Extract all files from this ZIP into a folder.
2. Close the player, including its tray icon, if it is already running.
3. Double-click Install-HourNerdMusicPlayer.cmd. It installs for your Windows
   account, adds Start menu/desktop shortcuts and registers Windows Installed
   Apps / Programs and Features. Administrator access is not required.
4. Open HourNerd Music Player from the Start menu.
5. Sign in with YOUR Pandora account. Your own stations will appear.

For updates, close the player and run the installer from the newer package.
To uninstall, use Windows Installed Apps / Programs and Features. Saved
accounts and settings are preserved. The original extracted folder remains
untouched; after installation you can archive or remove that extracted copy.
Running the EXE directly remains available for portable use.

Keep the EXE, supporting DLLs, EXE.config and public-distribution.flag together.
The public build uses a separate profile for each Windows user and does not
import the developer's or an existing Elpis development profile. Your settings
stay on your computer. No account, password, tokens or station history are
included in this download.

Requires Windows with the .NET Framework 4.8.1 runtime. Visual Studio and the
Developer Pack are NOT needed to run this prebuilt package.
Runtime download: https://dotnet.microsoft.com/en-us/download/dotnet-framework/net481
