HourNerd Music Player is a Windows Pandora client maintained by Chris Dahlkvist, based on Elpis by Adam Haile and its contributors.

Download **Setup.exe** for the installation wizard or **Setup.msi** for native Windows Installer installation. Choose one format per computer. Both include the application and supporting files; recipients do not run PowerShell or need Visual Studio.

Requires Windows with the Microsoft .NET Framework 4.8.1 runtime. Before signing in, open **Pandora connection setup** on the sign-in page and save the partner connection password, incoming key, and outgoing key supplied separately by your integration provider or administrator. It is not your personal account password, and is not included in the downloads. Without it the application cannot sign in or play music. The value is encrypted for your current Windows account on this computer. Then sign in with your own Pandora account to load your stations. No developer account credentials or listening history are included.

Features include a persistent station sidebar, Dark/Light/Midnight/Forest themes, HourNerd startup branding, About credits and optional developer tipping. Spotify support is not included.

This is an initial prerelease. Intermittent exits during station changes were reported during testing and have not been confirmed resolved. The build checks API regressions and MSI extraction; a successful build does not establish that all interactive playback behavior is stable.

Close the player before updating. When switching between EXE and MSI formats, uninstall the existing format first. Saved per-user settings are preserved. Public packages use a separate Public profile.
