# Contributing to HourNerd Music Player

Include your Windows version, app version, steps to reproduce, expected behavior, and the first build error or relevant diagnostic output. Keep passwords and account tokens out of reports.

Build with `Build-HourNerdMusicPlayer.ps1 -Test`. Changes to playback should be checked with live playback, station switching, next-track behavior and Sign out on Windows.

Preserve original source notices and the license. Add a dated modification notice when changing upstream files. See `AUTHORS.md` for project and original-author credits.
